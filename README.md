# ELITE Android Releases

This public repository contains only official signed Android APK release assets for the ELITE app. It does not contain the app source code.

- Download the newest version from the [latest release](https://github.com/nefkity189/elite-android-releases/releases/latest).
- The in-app update checker reads the latest release tag and downloads the `elite.apk` asset.
- Every release must use the same Android signing key and a higher `versionCode`.

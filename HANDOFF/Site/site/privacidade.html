Privacidade

Última atualização: 21 de novembro de 2026

Dados neste site

Esta página não solicita cadastro, e-mail ou localização. Para limitar a quatro os downloads iniciados pelo botão por dia, o site grava no Firestore do Firebase apenas a data no fuso de São Paulo e um contador agregado. Esse contador não identifica quem fez cada acesso e não é um mecanismo contra links diretos.

Download do aplicativo

O botão consulta a API pública do GitHub para localizar a versão mais recente. O arquivo APK é entregue pelo GitHub Releases, conforme os termos do GitHub. Ao abrir esses serviços, eles podem receber dados técnicos da conexão, como endereço IP e informações do navegador, segundo as políticas próprias.

Contato

Para dúvidas sobre privacidade, use os canais de contato informados no aplicativo ELITE.
